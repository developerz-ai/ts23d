# Research — Skills matrix: what 3D and design professions know, mapped onto ts23d

**Each profession that makes 3D things has a workflow, a vocabulary with measurable meaning and a
set of checks it runs before it calls work done. This page lists them per discipline, with sources,
and names the ts23d tool that carries each one, so the per-discipline skills in
[`.claude/skills/`](../../.claude/skills/) can load the right habits for a task.** Research as of
2026-11-07. Numbers from a fetched source carry its link; numbers from general practice are marked
*typical, verify*. Anything that maps to a planned tool is labelled **planned**. Methods are
learned from public practice; every design stays original ([16-art-as-text](../idea/16-art-as-text.md)).

## Matrix

| Discipline (skill) | Core skills | Standard workflow | Standards / measurable vocabulary | Checks before done | ts23d tools |
|---|---|---|---|---|---|
| Character artist ([`character-artist`](../../.claude/skills/character-artist/SKILL.md)) | anatomy, proportion, likeness-free original design, edge flow for deformation, hair, costume layering | brief → turnaround → block-out → primary/secondary/tertiary forms → retopo → bake → texture → present | heads-per-height 7–7.5 real, 8 heroic, 3–5 stylised; eye line at head middle; ≥ 3 loops at elbow/knee [S9][S10] | silhouette at thumbnail; value focus on head; joints deform | `head`, `sculpt`, `visualHull`, `ctx.joint` + `joints` gate, `assertJointsFit`, `t3d blueprint` (1.8 m figure), `t3d critique` |
| Creature artist ([`creature-artist`](../../.claude/skills/creature-artist/SKILL.md)) | comparative anatomy, function-first design, weight support, stance (plantigrade / digitigrade / unguligrade), surface (scales, fur) | purpose → real-animal borrowings → skeleton → masses → anatomy pass → surface → wear | purpose before form [S11]; limb cross-section grows faster than length with mass (allometry) *typical, verify* | stands (CoM over support polygon); attachments; LOD silhouette | `sculpt`, `visualHull`, `sd.*`, `assertCentreOfMassInside`, `assertUprightOnGround`, `creature` (**planned M4**), `T3D_ALLOMETRY` (**planned**) |
| Hard-surface / vehicle artist ([`hard-surface-artist`](../../.claude/skills/hard-surface-artist/SKILL.md)) | primary/secondary/tertiary shapes, controlled bevels, weighted normals, panel lines, mechanical logic | blueprints → block-out to scale → booleans/panels → bevel → mid-poly or bake → trim → present | bevel the edges that break the silhouette; face-weighted normals need bevels [S6]; shut-lines 3–6 mm (playbooks) | no lumps, no shading artefacts, every moving part clears | `box({ bevel })`, `weightedNormals`, `prism`, `extrudeSvg`, `lattice`, `real.measures`, `clashes`, `checks: [clear, touches, symmetric]`, `t3d gaps` |
| Environment artist ([`environment-artist`](../../.claude/skills/environment-artist/SKILL.md)) | modular kits, grid discipline, composition and leading lines, reuse ratio, terrain, foliage | block-out on grid → kit list → hero pieces → trims/tiling → set dressing → lighting pass | kit pieces snap to one grid; pivots at a corner; square footprints preferred [S7][S8] | seams hidden, repetition broken, scale from doors/stairs | `ctx.use` scenes, `defineFamily`, `tiled`, `mass`, `facade`, `heightfield` + erosion, `tree`/`trees`, `definePart`, `place`/`merge` |
| Prop artist ([`prop-artist`](../../.claude/skills/prop-artist/SKILL.md)) | real-object research, scale from a standard part, material breakup, story through wear | reference → measure → block-out → detail → materials → wear → present | one trusted dimension, 3–6 materials per object (playbooks) | reads at 3/4, grounded, budgets per LOD | playbooks `props/*`, `recipes/_parts`, `real` + `measures`, `grime`, `bakeAo`, `assertBudget` |
| Material / texture artist ([`material-artist`](../../.claude/skills/material-artist/SKILL.md)) | PBR theory, albedo/roughness/metal ranges, procedural graphs, tiling, trim sheets, wear masks | real swatch refs → height first → albedo → roughness → masks/wear → test on asset under neutral light | dielectric albedo ≈ 50–243 sRGB (charcoal ≈ 0.04 linear, fresh snow ≈ 0.8) [S12]; dielectric F0 = 0.04; metal albedo 0.5–0.98 linear [S12][S13] | tileable, no bleed, values plausible, texel density even | `tex.*` graph, `defineMaterial`, `materialVariant`, `weathered`, `finishes`, `optics`, `assertValueRange`, `assertTileable`, `assertNoBleed`, `assertTexelDensity`, `bun run textures` |
| Technical artist ([`technical-artist`](../../.claude/skills/technical-artist/SKILL.md)) | budgets (tris, draw calls, memory), LOD strategy, instancing, pipeline tooling, naming, validation | set budgets → author LOD policy → validate per LOD → profile → automate checks | owns "content budgets, LODs and instancing strategy" [S4][S5] | LOD silhouette holds, budgets met, deterministic bytes, validator clean | `budget.triangles`, `ctx.lod`/`ctx.pick`, `lodCoverage`, `--lods single` (MSFT_lod), `optimize`, `assertLodSilhouette`, `assertDeterministic`, `bun run bench`, `bun run verify` |
| Lighting & presentation artist ([`presentation-artist`](../../.claude/skills/presentation-artist/SKILL.md)) | three-point lighting, key:fill ratio, camera/focal length, turntables, readable thumbnails | neutral light → key → fill → rim → camera → greyscale check → sheet + beauty | key:fill 2:1 commercial, 4:1 portrait, 8:1 drama [S14] | subject fills frame, no clipped whites, shadow grounds it | `t3d hero` (`--az --el --fov --size`), `t3d shot`, `t3d review` warnings, `t3d critique` (raking light), `thumbnail`, `lodStrip`, light sockets → KHR_lights_punctual |
| Architect ([`architect`](../../.claude/skills/architect/SKILL.md)) | brief/programme, site, massing, codes, structure grid, envelope, daylight, BIM-style data | RIBA 0–7: strategic definition → brief → concept → spatial coordination → technical → … [S1]; NCARB AXP areas [S2] | 2R+G ≈ 550–700 mm (630 ideal), private stair rise ≤ 220 mm, pitch ≤ 42°, headroom ≥ 2.0 m [S15]; ADF ≥ 2 % kitchen / 1.5 % living / 1 % bedroom (BS 8206-2) [S16] | human-scale features right, storey heights consistent, openings on grid | `mass`, `setbacks`, `facade` + `split` grammar, `opening`, `roof`/`roofInfo`, `tiled`, `cell`, playbooks `buildings/*`, `t3d blueprint` |
| Industrial / product designer ([`product-designer`](../../.claude/skills/product-designer/SKILL.md)) | ergonomics/anthropometrics, DFM, CMF, surface transitions, user scenarios | research → sketches → foam/block models → CAD → CMF → DFM review → prototype | 5th-percentile female reach / 95th-percentile male clearance [S17]; draft ≈ 1° per inch depth, uniform walls (ABS 1.1–3.6 mm), ribs 50–60 % of wall [S18] | grips fit hands, walls not too thin, CMF sheet consistent | `assertMinThickness`, `assertBetween`, `ctx.joint({ kind: 'grip' })`, `paint` slots, `variants`, `finishes`, `ruler`, physics `massProperties` |
| Automotive designer ([`automotive-designer`](../../.claude/skills/automotive-designer/SKILL.md)) | proportion, stance, surfacing and highlights, character lines, DLO/greenhouse, wheel-to-body | package (hard points) → sketches → side view proportions → tape drawing → clay/digital → surfacing | dash-to-axle ratio (premium RWD long) [S19]; wheel ≈ ½ body height in classic proportion [S20]; stance = body on wheels [S21] | wheel-arch gap even, wheels fill arches, highlight lines continuous | `hull`/`hullLines`, `loft`, `sweep`, `lathe`, `_parts/wheel`, `real.measures` (wheelbase, track), `symmetric`, `finishes` clearcoat, zebra review (**planned**) |
| Concept artist ([`concept-artist`](../../.claude/skills/concept-artist/SKILL.md)) | thumbnails, shape language, silhouette, value grouping, iteration, design dossiers | brief → 20+ thumbnails → silhouettes → 3 roughs → callouts/turnaround → handoff | circle friendly, square stable, triangle danger [S22]; silhouette names the thing [S22] | readable as black shape; value groups clear | inline SVG + `svgShape` / `extrudeSvg` / `visualHull`, `defineFamily` variants for options, `t3d shot`, `assertSilhouetteMatches` |
| Rigger / animator basics ([`rigger-animator`](../../.claude/skills/rigger-animator/SKILL.md)) | joint placement at anatomical pivots, deformation zones, pivots for mechanics, clearances, arcs | skeleton → pivots → range of motion → deformation test → motion bake | pivot at the hinge line (playbooks); 2–3 loops per bending joint [S9][S10] | full-range motion clears; pivot at hinge | `ctx.group` pivots, `motion: spin/slide/sway`, `clashes`, `clearOf`, `assertMotionClear`, `assertPartMotionClear`, `ctx.joint`; skins/morphs **not shipped** |
| Game art director ([`art-director`](../../.claude/skills/art-director/SKILL.md)) | style guide / art bible, palette roles, scale rules, review cadence, consistency across a set | pillars → references → style guide → exemplar assets → reviews → enforce | palette entries carry usage roles; scale from doors, stairs, humans [S23]; "the guide is law until amended" [S23] | every asset on palette, same texel density, same proportions system | `definePalette`/`palettes`, trim sheet (one material), `defineFamily`, `assertTexelDensity`, `t3d critique` rubric, `critique.json`, gallery |

## Gaps these professions expose (ranked)

| # | Need | Who needs it | ts23d today |
|---|---|---|---|
| 1 | Skinning and morph targets: bones with weights, ≤ 4 influences, deformation test poses | character, creature, rigger | rigid pivots + baked `spin/slide/sway`; no skins, no morphs ([surfaces-volumes](surfaces-volumes.md)) |
| 2 | Readability gates: focal-point value contrast, value grouping, rest areas, shape-language metric | concept, art director, character | definitions only ([16-art-as-text](../idea/16-art-as-text.md), planned); `assertLodSilhouette` is the one shipped silhouette helper |
| 3 | Surface-quality review: zebra / reflection lines, curvature combs, section cuts, G1/G2 continuity | automotive, product | none; raking light in `t3d critique` only (zebra planned, roadmap "Reach") |
| 4 | Architectural programme and code checks: room areas, stair rule, door/headroom, daylight factor, egress | architect, environment | `blueprint` 1.8 m figure, `measures`; no stair part, no room/area model, no daylight analysis |
| 5 | Geometry-driven wear and set consistency: edge wear from curvature, flow streaks, cross-asset palette / texel / grid gate, modular-kit snap check | material, environment, art director, prop | `grime` (ground + zones), `bakeAo`, `weathered` strips; `weather()` planned; texel helper per asset only |

Also missing, smaller: custom light rigs / HDRI for `hero` (planned), `variations(n)` and GPU
instancing for set dressing (planned), ergonomic manikin beyond the fixed 1.8 m figure, DFM draft
analysis, `photoMatch` overlay (stub throws `T3D_NOT_IMPLEMENTED`).
