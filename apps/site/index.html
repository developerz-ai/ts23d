    How it works

    The agent writes code, looks at its own renders and fixes what it sees.

    1. 01 Ask your agent

      > /new-recipe Tiger I, mid-production 1943, fully stowed

      In Claude Code, Codex or any agent that writes TypeScript. The agent researches real dimensions and photos into recipes/tiger_1/README.md, then writes recipes/tiger_1/tiger_1.ts.

    2. 02 It renders, looks, fixes

      t3d shot renders orthographic views plus the far LOD with no GPU. The agent reads the image and edits the recipe; t3d build runs the QA gates.

    3. 03 Drop the GLB into your engine

      Unity, Unreal, Godot, three.js, Babylon: standard glTF 2.0, one GLB per LOD. Named nodes such as turret and wheel_* are pivots your code rotates or attaches to.
