ts23d

Plug it into Claude Code and build games.

A free 3D asset generator written in TypeScript. Your coding agent (Claude Code, Codex, or any model that writes TypeScript) authors each asset as a recipe module. Recipes compile to game-ready GLB with named, animatable parts. There's no GPU, no credits and no network, and the same recipe always produces the same bytes.

Play the demo Browse the recipes GitHub

  1. 01 Ask your agent

    > /new-recipe Tiger I, mid-production 1943, fully stowed

> Add a T-34 and make it drivable

    Real prompts for Claude Code in this repo. /new-recipe ships with the project.

  2. 02 It writes TypeScript, renders, looks, fixes

    t3d shot renders orthographic views plus the far LOD. The agent reads the image, edits the recipe and renders again. t3d build runs the QA gates.

  3. 03 Drop the GLB in your game

    Part names are the contract. The play demo below binds to them the same way.
